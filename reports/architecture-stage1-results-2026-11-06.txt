RESULTADO DE LA PRIMERA ETAPA - MVC Y WEBAPI

Implementado
- 668 rutas PUT/DELETE corregidas en 334 controladores API especializados.
- 1017 listados API paginados, con el mismo predeterminado 20 y limite 100 de MVC.
- 267 entidades con identificacion compuesta completa: servicio, controlador,
  repositorio, enlaces, formulario de edicion y confirmacion de eliminacion.
- Los formularios conservan la llave original en id; no la reconstruyen con
  campos editables o fechas que el navegador podria reformatear.
- GET por llave usa todos los componentes y SingleOrDefault; no toma la primera
  coincidencia de la primera columna. Llave incompleta devuelve 400.
- Respuestas de creacion API contienen Location con el identificador compuesto.
- MVC muestra errores de operaciones; API devuelve ProblemDetails con traceId.
- Las entidades ya cargadas con seguimiento conservan actualizaciones por columna;
  no se invoca DbSet.Update para marcar indiscriminadamente toda la entidad.
- Un solo registro de 1017 servicios compartido por ambos hosts.
- Cascadas: parametro de servidor correcto, texto seguro, cancelacion de respuestas
  antiguas y mensaje de error. Mapeo explicito incorporado en 96 vistas.
- Contrato API documentado en webapi-contract-2026-11-06.txt.
